# Kooperant CNC

Statický prezentační web vytvořený v čistém HTML, CSS a JavaScriptu. Je připravený pro nasazení na GitHub Pages bez sestavovacího procesu.

## Spuštění

Otevřete `index.html` v prohlížeči nebo spusťte jednoduchý lokální HTTP server v kořenové složce projektu.

## Nasazení na GitHub Pages

V nastavení repozitáře zvolte **Settings → Pages → Deploy from a branch** a vyberte hlavní větev a kořenovou složku.
